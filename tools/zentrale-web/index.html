      Dev-Instanz auf diesem Laptop starten

      Nur wenn der Laptop-Starter eingerichtet ist (simplemods://). Er holt den gewählten Stand und startet den Integration-Client (Fabric 26.3, alle Module).

      Ohne Starter passiert nichts – auf einem neuen PC zuerst unten einrichten.

      Neuen PC einrichten

      Einmal pro Windows-PC. Der Installer holt fehlende Werkzeuge per winget (Git, JDK 25, Python mit Pillow, cloudflared), richtet simplemods:// für deinen Benutzer ein und lädt den Code nach %USERPROFILE%\code\simplemods-dev. Admin-Rechte nur, falls Windows für ein Werkzeug danach fragt. Erneut ausführen = reparieren.

      1. Installer herunterladen
        ⤓ Installer (simplemods-install.txt)
      2. PowerShell öffnen (Start ▸ „PowerShell“), diesen Befehl einfügen, Enter
        …

      3. Im Browser die Anmeldung an der Zentrale bestätigen (einmal), danach Knöpfe oben nutzen
      simplemods:// reagiert nicht?
      • Fragt der Browser „simplemods-Starter öffnen?“, erlauben (Häkchen „immer“ setzen).
      • Passiert gar nichts: Installer erneut ausführen (Schritt 2). Test in PowerShell: Start-Process 'simplemods://fetch?ref=wave'
      • Fehler stehen im Popup und im Log %USERPROFILE%\.simplemods\starter.log (Installer: install.log).
      • „Lokale Änderungen im Dev-Ordner“: dort sichern oder git stash, der Starter überschreibt nichts.

      Mods für den Spielstart

      Deine Auswahl wird für dein Konto gespeichert und von den Start-Knöpfen mitgegeben: abgeschaltete Mods bleiben aus dem Mod-Ordner, abgeschaltete Sub-Mods einer laufenden Super-Mod bekommen „Enable Simple X“ = aus. Pflicht-Teile und benötigte Bibliotheken schalten sich selbst mit.
