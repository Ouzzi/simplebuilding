## Release notes

First release of **Simple Layers** for Minecraft 26.3 on Fabric.

Two new world layers: the **Cloud Sea** above the Overworld sky (floating islands, cloud shelves, mist pits, sky chests) and the
**Backrooms** below the bedrock (an endless grid of yellowed wallpaper rooms, damp carpet, buzzing neon lights, exit doors and rifts).
Cloud blocks break instantly and soften falls. Works on its own with Vanilla and SimpleLib.

## Highlights

- Cloud Sea dimension: enter by climbing above the configured height, slow fall when handed back to the Overworld
- Backrooms dimension: fall through the void below the Overworld floor, find the exit door or a rift to leave
- Blocks: cloud block, cloud stone, mist block, glitched bedrock, wallpaper (plain, striped, dotted), damp carpet, ceiling tiles, neon light, exit sign
- Ambient sounds (generated with ElevenLabs under a commercial licence, see CREDITS.md)

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API, SimpleLib

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simplelayers config` where available.
