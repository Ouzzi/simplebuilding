## Release notes

First release of **Simple Blocks** for Minecraft 26.3 on Fabric.

Missing building blocks: Hushed Deepslate Tiles that dampen vibrations like wool, Sculk Deepslate, the missing Vanilla stairs, slabs and walls and cracked/mossy brick variants. The Shapecutter cuts stone and wood into every stair, slab and shape. Works on its own with Vanilla.

## Highlights (from the commit history)

- Compressed rename, Collapsed stage with Slowness I-III and SimpleLib SlotAlert
- Compact/Dense blocks for 19 Vanilla bases
- Palette stage 2 A-D - 42 Simple Blocks members (mossy shapes, cracked prismarine/polished deepslate/blue nether, Vanilla-family walls/stairs/slabs) + 9 octets
- SimpleLib aging chains + Pale Garden blocks
- Variant A box for key pages and Shapecutter
- Simple Modpack guide in SimpleLib - top bookmarks per super-mod, chapters per mod as data
- Frost grass looks like Vanilla snowy grass, stage-0 Double Piston pushable
- One snow cap on fences, walls, stairs and slabs in snowfall

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Required mods: SimpleLib
- Optional integrations: simplebuilding, jei

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simpleblocks config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
