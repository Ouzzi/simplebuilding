## Description (Markdown)

# Simple Aesthetics

> **Beta.** This mod is released as a beta: features, balance and config options can still change between versions, and bugs are possible. Back up your world before you install or update it, and report problems on the issue tracker.

Simple Aesthetics has no content of its own. It bundles Simple Visuals, Simple Sounds and Simple Models with one on/off switch each.

## Features

- **Super-mod for looks and sounds** - Simple Aesthetics has no content of its own: it bundles Simple Visuals, Simple Sounds and Simple Models.
- **Commands** - /simpleaesthetics config shows and changes every option of config/simpleaesthetics.json (list [group], get, set, reset, help; Tab completes options and values).

## Dependencies

- **Required:** Fabric API (no other mods)
- **Included in this download:** SimpleLib, Simple Visuals, Simple Sounds, Simple Models
- **Optional:** none

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Super mod.** Its sub-mods (Simple Visuals, Simple Sounds, Simple Models) are included in this download; each can be switched off in the config ("Enable Simple XY") and each is also available on its own.
