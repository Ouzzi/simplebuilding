## Description (Markdown)

# Simple Foundry

Simple Foundry is a multiblock: a tank of melting chambers in a brick hull, fuel on the desk, ore thrown in, and the melt poured by layer through spouts into casting trays. Gold, copper and iron, one ingot per ingot.

## Features

- **Foundry (multiblock)** - Build a tank of melting chambers inside a closed hull, light it with fuel on the desk, throw in ore and pour the melt by layer.

## Dependencies

- **Required:** Fabric API (no other mods)
- **Optional:** Simple Ovens

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Standalone mod.** It works on its own; other Simple mods add optional extras when installed together.
