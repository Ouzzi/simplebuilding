# Simple Respawn

With Simple Respawn you are downed first. A teammate can revive you within the bleed-out time, and you return with three hearts and no food. A downed screen offers spectating, an inventory view and giving up.

## Features

- **Downed instead of dead**
- **Downed screen** - An own screen in the style of the Vanilla death screen shows the time left and three buttons: Spectate, Inventory and Give up.
- **Reviving** - A teammate holds right-click on the downed player for 5 seconds (reviveSeconds); afterwards the player stands up with 3 hearts and an empty food bar.
- **Fair play** - Leaving the game while downed is death; the real death is always the Vanilla one, so drops and other mods behave as usual.
- **Commands** - /simplerespawn giveup for the downed player (the Give up button); /simplerespawn down <players> and /simplerespawn revive <players> for game masters.

## Vanilla use

Replaces instant death with a downed state a teammate can revive; this is a clear change to how death works in multiplayer.
