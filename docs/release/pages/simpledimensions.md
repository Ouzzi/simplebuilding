## Description (Markdown)

# Simple Dimensions

Simple Dimensions lets you configure dimensions, build light arches and use linked portals that avoid unsafe destinations. It can cooperate with common claim mods.

## Features

- **Default Dimensions**
- **Skyblock** - Build one of six glowstone arches and place a separate emitting block within three blocks of the interior.
- **Mining Dimension** - Portal rows: DXXD / D..D / D..D / D..D / DEED.
- **Travel Dimension** - Portal rows: KRRK / O..O / O..O / O..O / SSSS.
- **Portal Shapes**
- **Safe Travel and Return** - Only unmounted players travel.
- **Configuration and Data Packs** - Server JSON: config/simpledimension/server.json.
- **Server Claim Permissions** - Enabled Simple Tweaks claims are checked through the public framework API.
- **Getting the Guide**
- **Inventory and Rights** - Your inventory stays with you: only unmounted players travel, items lying around, mobs and mounts stay behind.
- **Commands** - /simpledimension guide gives you the Simple Modpack guide with this chapter open (every player).

## Dependencies

- **Required:** Fabric API, Cloth Config
- **Optional:** SimpleBuilding, Mod Menu, Flan, FTB Chunks, Open Parties and Claims, GriefDefender, ClaimChunk
