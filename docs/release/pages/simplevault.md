## Description (Markdown)

# Simple Vault

Simple Vault hides a rare 2 x 2 gap in the Overworld bedrock. It leads to the Bedrock Vault: quiet halls on two floors in a dimension of solid bedrock. Three riddles of light, sound and path give you the seal parts that open the Ascent Altar, your only way back up.

## Features

- **The Bedrock Vault**
- **The three riddles** - Three chambers each hold a riddle; a froglight above the door shows its colour.
- **The ascent** - Set the three seal parts into the sockets of the Ascent Altar (yellow, violet, green).

## Dependencies

- **Required:** Fabric API, SimpleLib
- **Optional:** SimpleBuilding

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

**Standalone mod.** It works on its own; other Simple mods add optional extras when installed together.
