# Simple Optimization

> **Beta.** Diese Mod erscheint als Beta: Funktionen, Balance und Konfigurationsoptionen können sich zwischen den Versionen noch ändern, und Fehler sind möglich. Sichere deine Welt, bevor du die Mod installierst oder aktualisierst, und melde Probleme im Issue-Tracker.

> Keine Leistungsversprechen: Die Wirkung wurde noch nicht auf verschiedenen Rechnern und in Modpacks gemessen, deshalb nennt diese Seite keine Werte für FPS, Speicher oder Tickzeit. Das Ergebnis hängt von deiner Hardware und deinen anderen Mods ab.

Simple Optimization hat keine eigenen Inhalte. Sie bündelt drei Optimierungs-Sub-Mods mit je einem Ein/Aus-Schalter; jede tritt zurück, wenn eine bekannte Optimierungsmod ihren Bereich abdeckt.

## Funktionen

- **Super-Mod für Optimierungen** - Simple Optimization hat keine eigenen Inhalte: Es bündelt Simple Opt Render, Simple Opt Memory und Simple Opt Server.
- **Befehle** - /simpleoptimization config zeigt und ändert jede Option von config/simpleoptimization.json (list [Gruppe], get, set, reset, help; Tab ergänzt Optionen und Werte).

## Abhängigkeiten

- **Erforderlich:** Fabric API (keine weiteren Mods)
- **In diesem Download enthalten:** SimpleLib, Simple Opt Render, Simple Opt Memory, Simple Opt Server
- **Optional:** keine

## Kompatibilität

- Minecraft 26.3, Fabric Loader 0.19.5 oder neuer, Java 25
- Vorerst nur für Fabric.

## Teil der Simple-Familie

**Super-Mod.** Ihre Sub-Mods (Simple Opt Render, Simple Opt Memory, Simple Opt Server) sind in diesem Download enthalten; jede lässt sich in der Konfiguration abschalten („Simple XY aktivieren“), und jede gibt es auch einzeln.
