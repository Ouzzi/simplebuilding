# Simple Loot

> **Beta.** Diese Mod erscheint als Beta: Funktionen, Balance und Konfigurationsoptionen können sich zwischen den Versionen noch ändern, und Fehler sind möglich. Sichere deine Welt, bevor du die Mod installierst oder aktualisierst, und melde Probleme im Issue-Tracker.

Mit Simple Loot darf ein Spieler einen Tresor nach einer einstellbaren Zahl von Minecraft-Tagen (Standard 100) erneut plündern statt nur einmal.

## Funktionen

- **Tresor-Abklingzeit** - Ein Spieler darf einen Tresor nach vaultCooldownDays erneut plündern, Standard 100 Minecraft-Tage, Grenze 1–36500.
- **Befehle** - Berechtigung 2: /simpleloot vaults cooldown <Tage> und /simpleloot vaults repeat <true|false>; Speichern in config/simpleloot.json.
- **Sub-Mod von Simple QoL** - Allein spielbar (config/simpleloot.json).

## Abhängigkeiten

- **Erforderlich:** Fabric API (keine weiteren Mods)
- **In diesem Download enthalten:** SimpleLib
- **Optional:** Simple Quality of Life, Mod Menu

## Kompatibilität

- Minecraft 26.3, Fabric Loader 0.19.5 oder neuer, Java 25
- Vorerst nur für Fabric.
