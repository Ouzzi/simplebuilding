## Description (Markdown)

# Simple Weather

> **Beta.** This mod is released as a beta: features, balance and config options can still change between versions, and bugs are possible. Back up your world before you install or update it, and report problems on the issue tracker.

Simple Weather lets the server switch weather and lets each player change rain density on the client.

## Features

- **Disable weather**
- **Rain and thunder frequency**
- **Rain density**
- **Sub-mod of Simple QoL** - Playable alone (config/simpleweather.json).
- **Commands** - /simpleweather config shows and changes every option of config/simpleweather.json (list [group], get, set, reset, help; Tab completes options and values).

## Dependencies

- **Required:** Fabric API (no other mods)
- **Optional:** Simple Quality of Life, Mod Menu

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Sub-mod** of Simple Quality of Life. It is a required part of the super mod, and it loads without it as long as its own required mods above are installed.
