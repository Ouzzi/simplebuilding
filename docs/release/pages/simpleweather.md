## Description (Markdown)

# Simple Weather

Simple Weather lets the server switch weather and lets each player change rain density on the client.

## Features

- **Disable weather** - disableWeather (default false, server) clears rain and thunder and skips weather progression.
- **Rain and thunder frequency**
- **Rain density**
- **Sub-mod of Simple QoL** - Playable alone (config/simpleweather.json).
- **Commands** - /simpleweather config shows and changes every option of config/simpleweather.json (list [group], get, set, reset, help; Tab completes options and values).

## Dependencies

- **Required:** Fabric API, Cloth Config
- **Optional:** Simple Quality of Life, Mod Menu
