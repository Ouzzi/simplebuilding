# Simple Questionary

> **Beta.** This mod is released as a beta: features, balance and config options can still change between versions, and bugs are possible. Back up your world before you install or update it, and report problems on the issue tracker.

Simple Questionary adds a table that explains any item you put in, in an open book.

## Features

- **Questionary Table** - Put an item into the slot in the middle: the open book around it tells its lore, its use and a secret.
- **Questionary texts** - Every mod describes its own items in assets/<namespace>/questionary/<language>.json; resource packs can add or replace entries.
- **Placeholder texts** - Items without their own text still get a page: a short mood text picked from eight variants per item class, so the same item reads the same in every world.
- **Recipe facts** - The book reads the recipes of the world for the item in the slot and lists what it is made from and what it makes, with the crafting station.
- **Commands** - /simplequestionary config shows and changes every option of config/simplequestionary.json (list [group], get, set, reset, help; Tab completes options and values).

## Vanilla use

Explains any item you put in a table, for newcomers; it adds no gameplay of its own and does not change any Vanilla behavior.
