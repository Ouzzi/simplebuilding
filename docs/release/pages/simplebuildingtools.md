## Description (Markdown)

# Simple Building Tools

Simple Building Tools adds Building Wands (copper to Enderite and creative), the Octant in 17 colors and the Blueprint with an editor, picture import and cartography table copies.

## Features

- **Simple Building Tools: a sub-mod of SimpleBuilding**
- **Building Wand: whole areas in one click**
- **Octant: Measuring and Planning Shapes** - The Octant is SimpleBuilding's tape measure and planning tool.
- **Blueprint: Writing, Scanning and Building Structures** - A Blueprint stores a whole structure as a short, readable build code.
- **Old worlds**

## Dependencies

- **Required:** Fabric API, SimpleLib
- **Optional:** SimpleBuilding, Simple Ores, Simple Storage, Simple Hammers, Simple Octets

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Sub-mod** of SimpleBuilding. It is a required part of the super mod, and it loads without it as long as its own required mods above are installed.
