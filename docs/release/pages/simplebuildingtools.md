## Description (Markdown)

# Simple Building Tools

> **Beta.** This mod is released as a beta: features, balance and config options can still change between versions, and bugs are possible. Back up your world before you install or update it, and report problems on the issue tracker.

Simple Building Tools adds Building Wands (copper to Enderite, Enderite with Simple Ores, plus a creative wand), the Octant in 17 colors and the Blueprint with an editor, picture import and cartography table copies.

## Features

- **Simple Building Tools: a sub-mod of SimpleBuilding** - The Building Wands, the Octant and the Blueprint have their own mod; SimpleBuilding bundles it as a required sub-mod, and it runs on its own with only SimpleLib.
- **Building Wand: whole areas in one click**
- **Octant: Measuring and Planning Shapes** - The Octant is SimpleBuilding's tape measure and planning tool.
- **Blueprint: Writing, Scanning and Building Structures** - A Blueprint stores a whole structure as a short, readable build code.
- **Old worlds**

## Vanilla use

Speeds up large builds with wands, colored octants and the Blueprint; it only acts when you hold the tool, and it hooks the cartography table for blueprint copies.

## Dependencies

- **Required:** Fabric API (no other mods)
- **Included in this download:** SimpleLib
- **Optional:** SimpleBuilding, Simple Ores, Simple Storage, Simple Hammers, Simple Octets

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Sub-mod** of SimpleBuilding: included in that download, and it also runs on its own with the required mods above.
