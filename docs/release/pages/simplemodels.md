## Description (Markdown)

# Simple Models

Simple Models lets the server approve custom item models, assign them at the anvil, and browse them in a searchable screen.

## Features

- **Experimental Forge 26.3** - Opt-in Forge adapter with server-approved anvil models, catalogue networking, JSON configuration, and server tests.

## Dependencies

- **Required:** Fabric API (no other mods)
- **Optional:** SimpleBuilding, Mod Menu

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Sub-mod** of Simple Aesthetics. It is a required part of the super mod, and it loads without it as long as its own required mods above are installed.
