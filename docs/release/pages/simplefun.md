# Simple Fun

> **Beta.** This mod is released as a beta: features, balance and config options can still change between versions, and bugs are possible. Back up your world before you install or update it, and report problems on the issue tracker.

Simple Fun collects small playful mechanics, such as throwable bricks, toys and cosmetic transformations. Every effect is capped by the server, and bricks breaking glass is off by default.

## Features

- **Sneak Throw** - Sneak while dropping items.
- **Throwable Bricks** - Brick, nether brick and resin brick: throw with use.
- **Piggy Transformation** - Eating raw or cooked pork grants a cosmetic pig head for five minutes; milk removes the effect.
- **Damageless** - Feather melee and Damageless I deal zero direct melee damage, with knockback.
- **Knockback IV**
- **Admin Commands** - Permission level 2: /simplefun tweaks yeet toggle/strength; /simplefun tweaks bricks enable/breakGlass/damage/snowballDamage.
- **Brick Snowball** - Four snowballs around one brick craft one.
- **Flower Sniff** - Cosmetic delight: hold a flower and sneak.
- **Cookie Crumbs** - Cosmetic delight: eat a cookie.
- **Apple Sparkle** - Cosmetic delight: eat an apple.
- **Carrot Crunch** - Cosmetic delight: eat a carrot.
- **Melon Splash** - Cosmetic delight: eat melon.

## Vanilla use

Adds small playful items and toys, each capped by the server. On by default and each switchable: throwing items far while sneaking, throwing bricks with right click, a pig head after eating pork (milk undoes it) and Knockback IV; breaking glass with bricks is off by default.

## Dependencies

- **Required:** Fabric API (no other mods)
- **Included in this download:** SimpleLib
- **Optional:** Mod Menu, JEI, Jade

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Standalone mod.** It is not part of a super mod; install it on its own with the required mods above.
