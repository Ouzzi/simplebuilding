## Description (Markdown)

# Simple Optimization

Simple Optimization has no content of its own. It bundles three optimization sub-mods with one on/off switch each; each steps back when a known optimization mod covers its area.

## Features

- **Super-mod for optimizations** - Simple Optimization has no content of its own: it bundles Simple Opt Render, Simple Opt Memory and Simple Opt Server.
- **Commands** - /simpleoptimization config shows and changes every option of config/simpleoptimization.json (list [group], get, set, reset, help; Tab completes options and values).

## Dependencies

- **Required:** Fabric API, Simple Opt Render, Simple Opt Memory, Simple Opt Server
- **Optional:** none

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Super mod.** It requires its sub-mods (Simple Opt Render, Simple Opt Memory, Simple Opt Server); each sub-mod can be switched off in the config ("Enable Simple XY") and each can also be installed without the super mod.
