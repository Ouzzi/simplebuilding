## Description (Markdown)

# Simple Wanderers

Simple Wanderers adds one Wandering Trader per village with a leashed horse. Goods are split from the traveling trader, with a new stock every 3 days and a restock every 1.5 days. It works with Vanilla alone.

## Features

- **Village Wanderer** - One travel-cloaked trader per village: a Wandering Trader in an ochre cloak and a hat with a wide brim.
- **Wanderer's horse** - A normal horse in an ochre leather armor hangs on the wanderer's leash.
- **New stock and restock** - A fresh set of offers every 3 days and a restock every 1.5 days.
- **Goods: wanderer and traveling trader** - The goods of the Wandering Trader are split.
- **Biome assortment**
- **Commands** - /simplewanderers config shows and changes every option of config/simplewanderers-server.json (list [group], get, set, reset, help; Tab completes options and values).

## Dependencies

- **Required:** Fabric API (no other mods)
- **Optional:** SimpleBuilding, Simple Money, Simple Mobheads

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Standalone mod.** It works on its own; other Simple mods add optional extras when installed together.
