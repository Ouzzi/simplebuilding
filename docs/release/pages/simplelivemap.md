## Description (Markdown)

# Simple Livemap

Simple Livemap draws a web map from the chunks players visited and the maps they held, with relief and optional player positions. The built-in web server is off by default, local only, and can be locked with a key.

## Features

- **Explored chunks**
- **Map tiles**
- **Web map** - An optional built-in web server shows the map in the browser (drag, zoom, dimensions).
- **Private or public**

## Dependencies

- **Required:** Fabric API (no other mods)
- **Optional:** Simple Maps

## Compatibility

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Java 25
- Fabric only for now.

## Part of the Simple family

**Standalone mod.** It works on its own; other Simple mods add optional extras when installed together.
