# Simple Dinosaurs 0.1.0 - changelog (Minecraft 26.3, Fabric)

## Release notes

First release of **Simple Dinosaurs** for Minecraft 26.3 on Fabric.

Fossil block, dinosaur eggs you brush free and brood by sitting on them, and the first dinosaur: a rideable T. rex that hatches as a hatchling and grows up. Works on its own with Vanilla.

## Added

- **Fossil block** - A very rare find in the underground of deserts, badlands and swamps.
- **Dinosaur eggs** - One egg per dinosaur: T. rex, Triceratops, Stegosaurus, Utahraptor and Parasaurolophus.
- **T. rex** - The combat mount: three-quarter life size, a core hitbox of 3.6 x 3.5 blocks (head and tail reach beyond it).
- **Large saddle and T. rex armor** - The large saddle (a saddle, 4 leather and 4 iron ingots) fits only dinosaurs; one rider.

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Optional integrations: simplebuilding, simplemoney, simplemobheads

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simpledinos config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
