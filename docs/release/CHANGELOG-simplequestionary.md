# Simple Questionary 0.1.0 - changelog (Minecraft 26.3, Fabric)

## Release notes

First release of **Simple Questionary** for Minecraft 26.3 on Fabric.

The Questionary Table: put any item in and read its lore, its use and a secret in an open book.

## Added

- **Questionary Table** - Put an item into the slot on the left: the open book on the right tells its lore, its use and a secret.
- **Questionary texts** - Every mod describes its own items in assets/<namespace>/questionary/<language>.json; resource packs can add or replace entries.

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Required mods: SimpleLib

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simplequestionary config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
