## Release notes

First release of **Simple Mobs** for Minecraft 26.3 on Fabric.

Hollow Howler and Hollow Watcher bosses, Shellker, Soulfire Blaze, Dread and Deceiver mobs, Blighted and Abyssal Wither with Nether Heart and Red Nether Gem, and the Potion of Silence.

- Strong Upgrade (template + shard) moves to SimpleLib
- Shellker/Deceiver eggs back to pre-, Keys screens back to transparent style, Free Look wheel zoom
- Spawn eggs in the Vanilla 26.3 scheme, calmer boss textures
- Simple Modpack guide in SimpleLib - top bookmarks per super-mod, chapters per mod as data
- Feat: Jade/JEI show Simple Machines breaker pistons, admin book option, Simple Mobs trimStrength, mutations paths
- Move armour trim abilities out of the core

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Required mods: SimpleLib, Simple Resonance
