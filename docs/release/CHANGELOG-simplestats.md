## Release notes

First release of **Simple Stats** for Minecraft 26.3 on Fabric.

Every tool, weapon and piece of armor keeps its own statistics: blocks mined, kills by mob and variant, damage absorbed, distances, catches and more, with an item-specific statistics screen.

## Highlights (from the commit history)

- Simple Modpack guide in SimpleLib - top bookmarks per super-mod, chapters per mod as data
- Mod icons with characteristic motif on background tile, smaller strong upgrade shard
- Shared Hold-Shift tooltip in simplelib, resonance folds; head slot styled like armor slots, blocky head icon
- ST-40 guide books + FTB start quests for maps/tools/enddragonfight, ST-41 questionary texts
- Item stats, death vault, downed screen, models tab on simplelib blocks; contrast lint (ST-30..35)

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Optional integrations: simplebuilding

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simplestats config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
