## Release notes

First release of **Simple Animals** for Minecraft 26.3 on Fabric.

Five animals Vanilla does not have: the shy deer, the wild boar that defends its piglets, the hedgehog that hunts silverfish and rolls up in a flash, the rare sideways-walking crab and the zebra, a striped horse whose cross with a horse is the infertile zorse. Works on its own with Vanilla.

## Highlights (from the commit history)

- One clean creative tab per mod, family order
- Spawn eggs in the Vanilla 26.3 scheme, calmer boss textures
- Simple Modpack guide in SimpleLib - top bookmarks per super-mod, chapters per mod as data
- Pushable signal dampener without lever, double piston seam pair A, zebra/zorse compact model B, crab legs point down
- Rework generators - lead shapes/grid, zebra/zorse Vanilla head pose, dampener switch, double piston mid seam (preview only)
- Owner choices 31.10. built in
- Deer llama sounds, wild boar truffles + truffle soup, head-only mob heads, closed nautilus
- Biome coat variants (deer, boar, hedgehog, crab, T. rex), black-and-white zebra, A8b textures

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Optional integrations: simplebuilding, simplemoney, simplemobheads

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simpleanimals config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
