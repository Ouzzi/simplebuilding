## Release notes

First release of **Simple Mobheads** for Minecraft 26.3 on Fabric.

A head for every mob: dropped when a charged creeper's explosion kills it, worn for a small secret, placed, or played on a note block.

## Highlights (from the commit history)

- Simple Modpack guide in SimpleLib - top bookmarks per super-mod, chapters per mod as data
- Remove first pickup tips (), mirror chance by level, narrow pipe neck, gadget messages as sound/particles, dead Fabric tab hooks
- Deer llama sounds, wild boar truffles + truffle soup, head-only mob heads, closed nautilus
- ..3 evil rarity, nether heart/gem recipes, mighty/evil conduits, creative tab policy
- Feat: door sounds/placement, half doors retired, mob head GUI fit + shift-click, strong powder/TNT colours + recipe, enderite sink damper cap
- Simple Dinosaurs stage 1 - fossil block, eggs, brooding, T. rex
- New sub-mod simpleanimals (deer, wild boar, hedgehog, crab, zebra/zorse)
- Spyglass overlay as inverted UI window frame, flat/headless mob heads (horse family, warden feelers, camel/llama, ghast, mites, cod, creaking, elder guardian, glow squid)

## Requirements

- Minecraft 26.3, Fabric Loader 0.19.5 or newer, Fabric API
- Required mods: SimpleLib, Cloth Config
- Optional integrations: simplebuilding, simplemobs, simpleend, simpleenddragonfight, jei, modmenu

## Notes

- All options are in the config screen (Mod Menu / Cloth Config) and in `/simplemobheads config` where available.
- Back up your world before updating from an older SimpleBuilding build; old ids are migrated automatically.
