# Plan b-snow02 (Sitzung B, 01.11.): SNOW32-FALL Schnee bei Schneefall auf Zaun, Mauer, Treppe, Stufe

Basis `52f1f4ca3` (Production). Besitzer (SNOW32-FALL): "ja, aber nur eine layer, dann auch auf dem zaun oder was auch immer
eine layer schnee, also nur on top eine layer (quasi textur weiß oben aber wegmachbar)".

## Ist-Stand
- Simple Blocks (`com.simpleblocks.snow`): Snowlogging von Hand (`SnowloggedBlock`, Schnee am Zellboden mit getragenem Block),
  Frostgras, Config `snow.*` (`SnowConfig`). Vanilla `ServerLevel.tickPrecipitation` setzt Schnee nur in Luft mit
  `Blocks.SNOW.canSurvive` (volle Oberseite darunter) -> auf Zaun/Mauer/Treppe/unterer Stufe fällt nichts.

## Technik (begründet)
Eigener Block `simpleblocks:snow_cap` (Overlay) in der Luftzelle **über** dem Träger, statt Zustand/Block-Wechsel des Trägers:
- Trägerblock bleibt unverändert (keine Zustandszerstörung, Zaunverbindungen bleiben, keine Block-Entity, kein Mixin auf Vanilla-Blöcke).
- Eine Schicht, kein Stapeln: Kappe hat keine Kollision -> Heightmap MOTION_BLOCKING zeigt auf die Kappenzelle (nicht Luft) -> kein zweiter Schnee.
- Träger-Typen (`SnowCapBlock.supportBelow`): höchster Kollisionspunkt >= 1.0 ohne volle Oberseite (Zaun 1.5, Mauer, Scheibe, Treppe) = bündig;
  genau 0.5 (untere Stufe) = Zustand `lowered`, Modell/Form 8 px tiefer (Modell-Element y -8..-6). Volle Oberseiten bleiben Vanilla-Schnee.
- Weg: von Hand sofort (Härte 0,1), Schaufel gibt Schneeball (Vanilla-Beute), Licht > 11 schmilzt, Block hineinsetzen ersetzt, Träger weg -> Kappe weg.
- Hook: Mixin `SnowCapsMixin` HEAD auf `ServerLevel.tickPrecipitation` (kein Cancel). Kosten: Frühausstieg bei Config aus/kein Regen/Gamerule 0;
  nur beim Niederschlagstick (1 Spalte je Chunk mit 1/16 je Tick) und nur bei Schnee ein Heightmap-Lookup + 2 Blockabfragen.
- Config `snow.snowCaps` (Standard an), Category Snow, Tooltip + Lang EN/DE mit "Default:/Standard:".
- Keine neue Textur (Vanilla `block/snow`), also keine Vorschau nötig.

## Grenzen / Rückfrage
- Treppe: Kappe deckt die ganze Zelle (hintere Hälfte bündig, vordere Stufenhälfte darunter frei) - gut genug, sonst eigene Treppenform.
- Pflanzen/Blumen verschneien bei Schneefall nicht (Vanilla-Eingriff wäre stark, A12); nur Träger mit fehlender voller Oberseite.
