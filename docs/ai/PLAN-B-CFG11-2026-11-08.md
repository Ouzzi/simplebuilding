# Plan b-cfg11 (08.11.2026): Rest-Audit der SB-Config-Schlüssel auf 26.3

Fortsetzung von b-cfg10 (`PLAN-B-CFG10-2026-11-07.md`). Frage je Schlüssel: Wird er auf 26.3 im Kern (common/src/shared, mc26_3/overlay) noch
gelesen und wirkt? Wenn nein und ein Modul hat die Funktion → `ConfigOptions.MOVED_TO_*`. Wenn er nur an ein Modul weitergereicht wird → bleibt.
Methode: alle ~260 Felder aus SimplebuildingConfig/ServerTuningConfig/TweaksConfig per grep auf Leser geprüft (ohne config/, Tests, Lang),
danach je Leser-Klasse: registriert/aktiv auf 26.3 (McVersion-Flag, Mixin-Liste, Modul-Zwilling)? `@Excluded`-Felder sind keine Optionen.
