# Bericht claude-miniboss (Nachtrag 68, Minibosse)
- Howler: Groesse x1.3 per SCALE-Attribut (Hitbox + Modell, Cubes/UV/Textur unveraendert). Werte vs. Warden (500 HP / 0 Ruestung / 30 Schaden): 600 HP (+20 %), Schaden 34 (+13 %), Ruestung 8 (~20 % weniger Schaden, dafuer Kiefer-Schwachstelle x1.5). Config (simplemobs.json): howlerHealth, howlerAttack, howlerScalePercent (gelten beim Spawn; alte Howler behalten gespeicherte Werte).
- Minibosse: Howler und Dread (Annahme: "Knight" = Dread, beim Besitzer bestaetigen) mit ServerBossEvent, Titel "Miniboss: <Name> - <Phase>", Sichtbarkeit per Config bossBarRange (48), minibossBars schaltet ab. Howler: blau / gelb (Hunger) / rot (Wut). Dread: weiss, hat keine Lebensphasen, daher glatte Leiste.
- Jaws: Phase 2+ (Hunger, Wut) setzt je Intervall einen Sculk Jaw direkt unter einen Spieler ohne Jaw (HowlerLogic.jawTarget); sind alle belegt/nicht platzierbar, zufaellig 1.5-3.5 Bloecke neben einen (Luft, fester Boden). Config howlerJawMax (6), howlerJawInterval (100 Ticks). Ohne Simple Building Fallback auf Vanilla-Ranken wie bisher. Ersetzt die alten 3 Fallen rund ums Ziel.
- Phasenleisten: BossBars.overlayFor waehlt NOTCHED_6/10/12/20 passend zu den Grenzen: Howler 50/20 -> NOTCHED_10, Blighted/Abyssal Wither 50/15 -> NOTCHED_20 (per Accessor-Mixin WitherBossAccessor), Farbe + Name je Phase (Wither lila/rosa/rot). Ender Dragon (Vanilla-Leiste, keine Lebensphasen) bewusst nicht angefasst.
- Tests (neu, MinibossTests + Wither): howler_vs_warden, boss_phase_notches, howler_bossbar(_range), dread_bossbar, howler_jaw_rules, howler_jaw_spawn, wither_bossbar_phases; howler_registered auf 600/34 angepasst.
- Lauf 2 (Fabric+NeoForge module-simplemobs, simplemobs:*): Fabric "101 101 0", NeoForge 98/101 (jaw_spawn mit toetendem Echt-Jaw; danach Stand-in gehaertet, Nachlauf siehe Antwort); soulfire_charge/blaze rot auf NeoForge, nicht von mir beruehrt. Compile 3 Loader sauber.
- Nicht getestet: Client-Optik (Leistenfarben/Kerben), Forge-Gametests, JUnit, Server-Sicht mit echtem Spieler in Reichweite (Mock-Spieler nicht in level.players()).
- Offen: Merge nach wave1, Besitzer-Abnahme "Knight" = Dread, Wiki/Guide-Hinweis auf Boss-Leisten.
