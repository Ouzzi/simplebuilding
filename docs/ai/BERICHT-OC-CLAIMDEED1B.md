# Bericht oc-claimdeed1b: Claim-Urkunde Phase 1 (Rechte/Parser/Ledger/Hooks)
Plan: `docs/ai/PLAN-CLAIM-URKUNDE-GUI-2026-10-13.md`. Keine GUI, kein Claim-Tisch, keine Maps-Ebene, keine Erweiterung.
- **Rechte:** `ClaimRights` (B D U C R A M, Rollen @guest/@helper/@member/@manager, `*`); `Rules` je Person + Alle; Abschnitt `[x,z]` ersetzt den oberen Teil für seinen Chunk; Person + `*` addieren sich.
- **Parser `ClaimCode`** (nur Server entscheidet): 4096 Zeichen / 200 Zeilen / 96 je Zeile / 32 Abschnitte / 16 Fehler hart vor dem Parsen; Fehler mit Zeile+Schlüssel; Namen nur online (kein Netz). `Claims.applyCode` (Besitzer; Verwalter-Grenzen §3.5, Abklingzeit, alles-oder-nichts).
- **Ledger v2** (`ClaimStore`): `claims[]` + `lands[]`; Migration v1/NBT → @member (oberer Teil bei gleicher Liste, sonst Abschnitt je Chunk, kein Rechte-Gewinn, kein M); erste v2-Schreibung sichert `simpletweaks-claims.v1.json`; unbekannte Version/Bits → gesperrt. MAX_BYTES 32 → 64 MiB (Plan F9).
- **Hooks:** Framework `Protection.Action` + `allows(target, action)` (alte Aufrufe = ANY = B+D); Claims-Hooks: Abbau D, Block-Item/Eimer ausgießen B, Tags `simpletweaks:claim_use`/`claim_redstone` U/R, Container/Menüblöcke C, Tiere/Fahrzeuge A, Rahmen/Ständer/Aufheben C, Spieler jedes Recht, Rest streng B+D; neuer `ClaimItemUseMixin` (Item-Fallthrough streng). SB `WorldPermissions.Action` (Hammer/Laser-Abbau DESTROY, mayPlace BUILD, Entities ENTITY; Rest ANY).
- **Befehle pro Chunk:** `/claim trust <p> [@rolle|Buchstaben]` (Abschnitt des Chunks, ohne Angabe @member), `untrust`, neu `info`, `code`.
- **Tests:** 6 neue GameTests (`claims_rights_*`: parser_good/bad, action_matrix, apply_code, commands, migration) + 50 bestehende Claims-Tests angepasst/grün. `module-simpletweaks-fabric-263` und `-neoforge-263`, Filter `simpletweaks:claims*`: beide „alles gruen: 56/56“.
