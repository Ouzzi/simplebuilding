# Plan A-ORES07 (06.11.2026): Nether-Roségold-Erz, Sage Crystal, Sage-Erze in Nether/End (Wünsche 061106, Punkte 1, 4, 5)

Ist-Stand: kein Nether-Roségold, kein Sage Crystal; Sage Ore nur Oberwelt (sage_ore, deepslate_sage_ore, Drop Sage Orb). Rose Gold hat KEIN Rohmaterial (Pressling -> Hochofen -> Barren).

## Entscheidungen (begründet)
- **Name:** `nether_rose_gold_ore` ("Nether Rose Gold Ore" / "Nether-Roségolderz"). "rose copper/rosegold" des Besitzers = Erz der Roségold-Familie (Rosenkupfer wird aus Roségold legiert, hat kein eigenes Erz).
- **Drop:** `rose_gold_pressling` (1, Glück ok, Behutsamkeit behält das Erz). Grund: es gibt kein Roh-Roségold; der Pressling ist die Vorstufe der Kette und schmilzt im Hochofen zum Barren. Das Erz selbst schmilzt in Ofen/Hochofen direkt zum Barren (wie Nethergold-Erz).
- **Worldgen:** `simpleores:rose_gold_vein` = `OreFeature`-Unterklasse; Ziel-Liste [Roségold-Erz, Nethergold-Erz] auf `base_stone_nether`. `canPlaceOre` würfelt für den Roségold-Eintrag (Config `roseGoldOreChance`, % je Nethergold-Block, Standard 2, Bereich 0-10), nur y < 31 (Lava-Ozean), nur solange in DIESEM `place()` noch keiner gesetzt wurde (ThreadLocal) -> höchstens 1 je Ader. Die zwei Vanilla-Placements `ore_gold_nether`/`ore_gold_deltas` werden per Fabric-BiomeModification (REPLACEMENTS) durch gleich parametrierte eigene ersetzt (nur bei Modul an).
- **Sage Crystal:** Barren-Familie (Zutaten-Tab, `c:ingots/sage_crystal`), 9 <-> `sage_crystal_block`. **Shards:** `sage_crystal_shard`, 2x2 Shards -> 1 Crystal (wie Amethyst-/Quarz-Muster, kleinste Rezeptform).
- **Sage-Erze Nether/End:** `nether_sage_ore` (Netherrack), `end_sage_ore` (Endstein); Drop 1-3 Shards (Glück), Erfahrung 2-5; Adern 4, Nether 5/Chunk (Y 10..117), End 3/Chunk äußere Inseln. Config `sageOreOtherDimensions` (Standard an) schaltet beide.
- **Texturen:** Vanilla-abgeleitet, gebaut (ores_2026_10_30.derived): Roségold-Erz = Nethergold-Erz mit Rosé-Flecken; Sage-Erze = Netherrack/Endstein + Sage-Flecken des vorhandenen Sage-Erzes; Crystal/Block auf Sage-Rampe. Vorschau mit Varianten, A eingebaut.
- NUR 26.3 Fabric; NeoForge/Forge-Biome-Modifier nicht angefasst (offen, Port).
