# PLAN b-tromp14 (09.11.) – N10a Trompete stumm

Besitzer 09.11.: „Trompete kann man nicht hören, keine Sounds.“ Basis hub/b-bundle163-gen (ac42dcfdb).

## Ist-Stand
simplemobs:trumpet (a-misc05, Bündel 111): TrumpetItem (Server, onUseTick) → TrumpetNet-Payload an Spieler im Umkreis →
client/TrumpetLoop (AbstractTickableSoundInstance, looping, folgt dem Spieler, Fade-in/-out über `gain`).

## Ursache (systematisch geprüft)
| Prüfpunkt | Ergebnis |
|---|---|
| sounds.json `item.trumpet.low/high` → `simplemobs:item/trumpet/{low,high}` | Dateien vorhanden (Namensraum, Ordner, Klein-schreibung ok); check_missing_textures grün |
| .ogg gültig | Ogg Vorbis, **mono**, 44,1 kHz (file/Header) |
| Registrierung | MobsSounds.registerAll (Fabric), Test trumpet_use prüft beide IDs |
| Netz | TrumpetNet sendet Start/Wechsel/Stopp (Test trumpet_net grün) |
| **Abspielen** | **FEHLER:** `Loop` startet mit `volume = 0` (Fade-in in tick()). Vanilla `SoundEngine.play` (26.3, Z. 411–416): Lautstärke 0 und `!canStartSilent()` → „Skipped playing sound …, volume was zero.“ → `NOT_STARTED`. Die Instanz wird nie gestartet, tick() läuft nie, Voice bleibt hängen → komplett stumm. |

## Fix
`TrumpetLoop.Loop.canStartSilent()` → `true` (Vanilla-Muster BeeSoundInstance): Sound startet stumm, tick() blendet in 4 Ticks ein.

## Absicherung
- Statischer Check: `tools/check_missing_textures.py` neu `check_silent_sound_starts` – jede `extends Abstract(Tickable)SoundInstance`
  mit `volume = 0` ohne `canStartSilent` ist ein Fehler (gegen die alte Datei geprüft: rot; mit Fix: grün; 3 Instanzen im Repo,
  nur die Trompete betroffen). sounds.json→.ogg prüfte das Skript schon (N66).
- Gametest `simplemobs:sound_files` (ModuleGameTest.soundFiles): jedes MobsSounds-Event registriert, Eintrag in sounds.json,
  jede Datei per Classpath auffindbar, Ogg-Vorbis-Header, mono.
- Client-Audio-Lauf nicht möglich/billig (kein Audiogerät im Testlauf, Client-Läufe macht das Bündel) → Bündel-Client: Log auf
  „volume was zero“/„Unable to play“ prüfen; Hörabnahme Besitzer.
