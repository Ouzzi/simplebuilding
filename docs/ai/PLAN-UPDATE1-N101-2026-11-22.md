## 3. Entscheidungen von B (begründet)
1. **Interface-Rail in `simplestorage`** (dort liegt der Verbund), vier Ids `interface_rail`, `reinforced_interface_rail`,
   `netherite_interface_rail`, `enderite_interface_rail`; Raten = Trichter-Abklingzeit 8/4/2/1 Ticks, je Takt ein Stapel-
   anteil wie ein Trichter gleicher Stufe (liest `MachinesConfig`, wenn `simplemachines` geladen ist, sonst dieselben
   Standardwerte – keine harte Abhängigkeit). Die Schiene ist Verbund-Knoten, wenn ein Interface oder Kabel sie berührt.
   Lore-Arten über Vanilla `AbstractMinecartContainer` (Truhe, Trichter, auch `TierHopperMinecart`); **Ofen-Lore**: hat
   kein Inventar → „annehmen“ = Brennstoff aus dem Verbund nachfüllen, nichts entladen.
   Modus: **ohne Redstone = entladen (Lore → Verbund), mit Redstone = beladen (Verbund → Lore)**; die Lore hält auf der
   Schiene, bis leer bzw. voll, dann fährt sie weiter (wie ein Vanilla-Aktivierungsgleis gedacht). Siehe 7.
2. **Trompete**: neues Item-Modell (3D-Trompete wie Spyglass-Größe) + eigene Pixel; Klang neu als physikalisch modellierter
   Blechbläser-Ton (Lippen-Anregung + Röhren-Resonanz, leichter Ansatz und Vibrato) aus dem eigenen Skript; **8 Stufen
   C-Dur über eine Oktave** (Blickwinkel ±15° bleibt), Schleichen = gleiche Stufen eine Oktave tiefer; ein Sample je Oktave.
3. **Ender-Herz**: Block `simplemobs:ender_heart` nach Muster `NetherHeartBlock` (eigene Form/Modell); das Item wird
   `BlockItem` mit **derselben Id** (keine Id-Änderung).
4. **Gems**: ein gemeinsamer `GemBlock` (stehender facettierter Edelstein, Form aus Elementen, durchscheinende Facetten,
   leichtes Eigenlicht wie das Item andeutet); `nether_gem` bekommt das neue Modell, `ender_gem` wird neu Block (Item →
   `BlockItem`, gleiche Id).
5. **Autostripper**: `strip_station` bleibt Id der Grundstufe („Stripper“), neu `reinforced_/netherite_/enderite_strip_station`;
   Tier-Rezepte wie die Trichter (Reinforced Werkbank, Netherite/Enderite Schmiedetisch). Zug = alle 4 Ticks bei gehaltenem
   Rechtsklick (Vanilla-Wiederholtakt); Menge = Stufe × (Enderite-Axt ? 2 : 1); Haltbarkeit = ceil(Menge / 2) mit
   Unbreaking; Zug wird gekürzt bzw. ausgelassen, wenn die Axt ihn nicht überlebt (nie kaputt). Ausgabe: Trichter unten
   nimmt; ohne Trichter wird das Ergebnis nach jedem Zug oben ausgeworfen. Renderer zeigt Stämme größer (≈ 12/16 statt heute).

## 5. Risiken
- **Kompatibilität (Erst-Release-Spieler):** Der Autostripper wird für bestehende Spieler **langsamer** (heute ganzer Stapel
  je Klick, künftig 2/4 je Zug) – vom Besitzer gewollt, im Changelog nennen. Interface-Rail berührt den Verbund
  (`ChestNetwork`): Lore als Verbund-Quelle darf Controller-Zählung/Kapazität nicht verändern (Regressionstest
  `NetworkTests`). Andere Lore-Mods: nur Vanilla-Container-Schnittstelle nutzen.
- **Welt-Migration / IdMoves:** keine Id wird umbenannt. `ender_heart`/`ender_gem` werden von Item zu BlockItem mit gleicher
  Id → Stacks bleiben gültig; `nether_gem`-Block bekommt neues Modell, Blockzustände unverändert (sonst Zustands-Test für
  alte Paletten). Neue Ids = keine IdMoves. Strip-Station-BE-Daten bleiben gleich (Zug-Zustand nur zur Laufzeit).
- **Texturen / Vorschau-Karten:** viele neue Pixel (Trompete, 3 Stripper-Stufen, 4 Rails, 2 Modelle) → alles in **N101**
  (eine Karte, ok/Einwand je Bild auf der Detailseite); Klänge synthetisch eigene (keine Fremd-Audio), Hörprobe Pflicht.
- **Performance:** Interface-Rail tickt nur mit Lore darauf (Lore-Suche per Block-Tick, kein Dauer-Tick); Enderite-Rail
  1 Takt/Tick über Verbund-Suche → Ziel-Kiste cachen wie der Controller; Autostripper-Zug serverseitig gedrosselt.
