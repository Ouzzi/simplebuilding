## Schnittstellen
- Modul `modules/simpleearth`, Paket `com.simplebuilding.modules.simpleearth`, nur Fabric, braucht simplelib (UI-Kasten) + framework,
  SB optional (`parent simplebuilding`, `bundle optional`, Schalter `enableSimpleEarth`, in SB gebündelt).
- Server-Config `config/simpleearth-server.json` (`EarthServerConfig`): enabled, dimensions, minActivationY, minSwitchGap, maxOrbitSpeed,
  minEdge/maxEdge, exploredOnly, showOthers, workerThreads, tilesPerSecond, memoryTiles, diskCacheMiB, slowFallSeconds.
- Client-Config `config/simpleearth-client.json` (`EarthClientConfig`): gewählte Version + je Version V1–V9 eigene Werte
  (Schema `EarthSettings`: gemeinsame Werte Aktivierungs-/Umschalt-/Deckenhöhe, Kante, Flugtempo, Abtastraster, Rundung, Atmosphäre,
  Mondgröße, Sterne + versionsspezifische Werte, je mit min/max/Schritt/Standard). Dasselbe Schema füttert die Scroll-Liste im Menü.
- Netz: C2S `OrbitConfigPayload` (Höhen/Kante/Tempo der gewählten Version, Server klemmt), C2S `OrbitMovePayload` (Gleitschritt je Tick,
  Server klemmt auf Tempo), C2S `TileRequestPayload` (bis 64 Kacheln), S2C `OrbitStatePayload` (aktiv, Mitte A, Orbit-Position, geparkt,
  wirksame Werte, andere Orbit-Spieler), S2C `EarthTilePayload` (Raster-Exponent, Kachel, 64 × 64 gepackte Kartenfarben, deflate).
- Terrain: globales Raster, Schritt 2^e Blöcke (e 4 … 14), Kachel 64 × 64 Abfragen; Pixel = Vanilla-Kartenfarbe (`MapColor` Paket-ID,
  Biom → typischer Oberflächenblock, Helligkeit wie Vanilla-Karte aus Höhenvergleich mit dem nördlichen Nachbarn, Wasser nach Tiefe).
  Server: `TerrainSampler` (rein Weltgen, Worker-Pool, nie Haupt-Thread), `TileStore` (LRU im Speicher + Datei
  `<welt>/data/simpleearth/<dim>/<e>/<tx>_<tz>.bin`, Grenze MiB), Budget je Spieler.
- Orbit (Server `OrbitTracker`): ab Aktivierungshöhe Mitte A merken; ab Umschalthöhe parken (Client hält x/z fest, Gleitschritte bewegen
  nur die Orbit-Position); unter der Umschalthöhe Wiedereintritt = Teleport an die Orbit-Position + Langsamfall; unter der Aktivierungshöhe aus.
  Unten bleibt alles Vanilla (keine Änderung an Sicht-/Kartenreichweite, Chunks nur in normaler Sichtweite).
- Client: `EarthClient` (Zustand, Kachel-Anfragen nach Sichtbarkeit), `FaceTextures` (Flächenbilder aus Kacheln, LRU), `EarthRenderer`
  (Hintergrund, Sterne, flache Sonne, Würfel-Mond, Erdkörper, Atmosphäre, Linien), Varianten als **reine Klassen** ohne MC-Typen:
  `variant/V1…V9` erzeugen je Bild eine `Scene` (Netzstücke mit Kachel-Versatz, Spiegelung, Mischung, Deckkraft; Linien; Kontaktpunkt).
- V7–V9 (neu, Tesserakt-Charakter von V6): **V7 Zellen-Netz** (V6-Faltnetz aus flachen Würfelzellen mit Scharnier-Linien = Dalí-Kreuz),
  **V8 Netz + Umstülpen** (V6, an der Ecke statt Bildüberblendung die Tesserakt-Umstülpung aus V3 mit Eckfenster),
  **V9 Faltschale** (getrennte Profilkurven in x und z: alle 25 Kacheln lückenlos verbunden, Eckkacheln als Parallelogramme,
  nirgends Überblendung nötig). Vorher Skizze `/root/sb-tools-b/previews/wc24-4-earth-v7-v9.html`.
- Menü `EarthScreen` (Taste O + Dev-Knopf): Kasten rechts, Bildschirm frei, Bewegung läuft weiter (Octant-Muster), 9 Versionsknöpfe,
  Scroll-Liste der Werte der gewählten Version (Regler, Mausrad, Zurücksetzen), Werte live; Vanilla-naher Rahmen (`UiBoxes`), Kontrast ≥ 4,5:1, DE/EN.

## Risiken
- **Render-Pipeline 26.3:** Eigene Geometrie über `submitCustomGeometry` mit `RenderTypes.text(...)`-Texturtyp (Farbe × Textur, volles Licht);
  Nebel/Ferne: der Erdkörper wird verkleinert nahe der Kamera gezeichnet (≤ 180 Blöcke), Hintergrund innerhalb der Sichtweite.
  Shader (Iris) ungeprüft – Abschnitt im Fragen-Dokument.
- **Leistung:** Abtasten nur im Worker-Pool (Standard 2 Threads), Fortschritt grob → fein (64/128/256 px je Fläche), Budget je Spieler,
  Speicher-/Datei-Cache; Client baut Flächenbilder nur bei neuen Kacheln oder Mischstufen-Wechsel (1/16-Stufen).
- **Mehrspieler / Seed-Schutz (E8):** Client bekommt nur Kartenfarben, nie den Seed; `exploredOnly` blendet Gebiete ohne Regionsdatei aus;
  Server klemmt alle Client-Werte, prüft Gleitschritte gegen das Tempo, Weltgrenze stoppt die Orbit-Position.
- Parken: verlässt der Spieler das Spiel im Orbit, steht er beim nächsten Login über dem Parkpunkt (Orbit-Position geht verloren) – als Frage notiert.
- Client-Sicht: nur ein Client-Lauf erlaubt; Optik/Gefühl im echten Spiel bleibt Besitzer-Abnahme.
