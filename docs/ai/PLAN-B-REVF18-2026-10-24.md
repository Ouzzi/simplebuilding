# Plan B: REV24-F-18 Hammer-Amboss-Logik Kern -> Simple Hammers (24.10.)

Grundlage: `docs/ai/PLAN-B-REVSTATE24-2026-10-24.md` Abschnitt REV24-F-18. Nur 26.3 Fabric.

## Ist
- `common/src/shared/java/com/simplebuilding/mixin/AnvilScreenHandlerMixin.java`: HEAD-Inject `updateResultHead`
  (Hammer+Hammer: Haltbarkeit + 12 % Bonus, Verzauberungen wie Vanilla kombiniert, Kosten 1; Hammer+Material:
  1/11 je Stueck, Kosten = Material (+1 Umbenennen), max 39), RETURN `applyAnvilTweaks` Teil A (Hammer-Ergebnis:
  `repair_cost` 0, Kosten < 40). Uebrige Teile (Aufladen, Strukturkompass, Farbpalette, anvilRepairKeepsCost) sind
  kein Hammer-Code. `mayPickup` hat keinen Hammer-Zweig: Vanilla nimmt Kosten >= 1, die der Hammer-Zweig immer setzt.
- Simple Hammers wird nur fuer 26.3 gebaut (`gradle/module-fabric.gradle` = mc263); 26.2/1.21.11 haben kein Modul.
  Standalone hat heute keine Amboss-Regeln (Prinzip-Verletzung).
- Vorhandenes Muster: Kern-`CarvedStairMixin` fragt `McVersion.HAMMERS_IN_SB` ab (26.3 false), das Modul hat den
  eigenen Mixin ohne Bedingung.

## Aenderung
1. Neu `modules/simplehammers/shared/java/com/simplehammers/engine/HammerAnvil.java`: reine Rechnung
   (`result(left, right, itemName)` -> Ergebnis, Stufen, Materialverbrauch oder null), Logik 1:1 aus dem Kern.
2. Neu `modules/simplehammers/shared/java/com/simplehammers/mixin/HammerAnvilMixin.java` (`@Mixin(AnvilMenu)`):
   HEAD `createResult` -> HammerAnvil, RETURN -> Hammer-Ergebnis `repair_cost` 0 / Kosten < 40; in
   `simplehammers.mixins.json` eintragen.
3. Kern-Mixin: Hammer-Zweige nur bei `McVersion.HAMMERS_IN_SB` (Konstante, auf 26.3 tot) -> auf 26.3 rechnet nur das
   Modul, auf 26.2 nur der Kern. Hammer-Ergebnis faellt auf 26.3 nicht in den anvilRepairKeepsCost-Zweig des Kerns.
   Abweichung vom Plan: kein Mixin-Plugin noetig, weil das Modul auf 26.2 gar nicht existiert (Muster CarvedStairMixin).
4. Tests: `HammerTests` `anvil_hammer_combine` + `anvil_hammer_repair` (+ Fabric-Adapter `ModuleGameTest`) laufen in
   module-simplehammers-fabric-263 und -standalone-; Kern: vorhandener `rev_core24...anvil_hammer_combine...` in
   fabric-263/integration-263 (prueft die einfache Verarbeitung mit SB: Kosten genau 1, Haltbarkeit einmal addiert).
5. Wiki/Guide-Texte pruefen (Fundstellen-Pfade in manual.json), Generatoren, `./gradlew check`.
