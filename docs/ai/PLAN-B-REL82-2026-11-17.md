## 7. simpledinos-2: Fossil species can be chosen by relocating (audit P3-5) -> b-dino82
- Ist: `FossilBlockEntity.kind()` rolls the kind from position and biome. Silk Touch drops a plain fossil item, so the kind
  is lost, and at the new place it rolls again: move until the wanted egg comes.
- Change: data component `simpledinos:fossil_sort` (int, like Simple Foundry's `desk_tier`). The block entity writes it in
  `collectImplicitComponents` (rolling first, at the find site) and reads it in `applyImplicitComponents`; the Silk Touch
  entry of the loot table copies it (`copy_components`, source `block_entity`). Placing an item with the component keeps
  the kind, no re-roll. Items without it (creative, old stacks) roll at the new place as before.
- Registration on all three loaders (Fabric `registerAll`, NeoForge/Forge `RegisterEvent` for DATA_COMPONENT_TYPE).
- Texts: questionary secret, wiki manual (fossil feature + note) EN+DE; check_data asserts the copy.
- Test: gametest `fossil_silk_touch_keeps_kind` (Silk Touch drop carries the kind; placed by a player at a spot that would
  roll another kind, the block keeps the carried kind; a plain item still rolls the spot's kind).

## 8. simpledinos-2: Utahraptor without own sounds -> b-dino82
- Ist: parrot/fox/chicken placeholders in `Utahraptor`.
- Choice: procedurally synthesized own .ogg files (option 2), generator `tools/sounds/make_raptor_sounds.py` on the
  existing `howler_dsp.py` toolkit (glottal source, small-throat formants, breath, room, loudness by active RMS); fixed
  seeds, mono 44.1 kHz Vorbis via ffmpeg. No Mojang audio is used or committed.
- Events (DinoSounds, registered on all loaders automatically): `entity.utahraptor.ambient` (chirping trills),
  `.hurt` (sharp yelp), `.death` (falling screech into a rattle), `.angry` (hiss with a throat growl), `.step` (light
  talon click). sounds.json entries with subtitles, EN+DE lang keys. Voice pitch centred on 1.0 (hatchling 1.35).
- Docs: wiki manual utahraptor line, Utahraptor javadoc, CREDITS.md (procedural, own work).
- Test: gametest `utahraptor_has_own_voice` (its events are the registered simpledinos ones); check_data asserts that
  every DinoSounds event has a sounds.json entry, existing .ogg files and EN+DE subtitles.
