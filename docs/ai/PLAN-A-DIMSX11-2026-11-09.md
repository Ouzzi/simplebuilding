## 3. Umsetzung
1. `/simpledimension guide` (jeder Spieler): gibt das Modpack-Handbuch, schaltet das Kapitel frei (Advancement guide/chapter).
2. Beim ersten Betreten einer Mod-Dimension (nicht Rückkehr): Handbuch + Kapitel freigeschaltet, einmalig (Advancement guide/welcome),
   Config `giveGuideOnFirstTravel` (Standard an, Reiter Zugang, Server).
3. Manual: neue Funktionen `default_dimensions` (Übersicht, Erststart, Schalter), `guide_access` (Rezept, Befehl, erster Besuch),
   `inventory_rights` (Inventar bleibt beim Spieler, nur Spieler reist, Rechte/Claims, Befehl Stufe 2); `commands` ergänzt. Generator
   tools/guides/module_guides.py neu laufen lassen (Seiten, Lang, Java, Wiki).
4. Lang EN/DE, config-options.json, Config-Screen, check_data.py.
5. Gametests (Katalog + @GameTest-Adapter): `default_dimensions` (3 Configs da, 3 Dimensionen im Registry-Zugriff, Schalter Standard an),
   `guide_recipe` (Buch + Werkbank ergibt Handbuch), `guide_content` (Seiten der Default-Dimensionen im Lang), `guide_welcome` (Befehl/erste Reise gibt Buch einmalig).
