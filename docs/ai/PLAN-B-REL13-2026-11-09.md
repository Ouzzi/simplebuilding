   Dev-Erkennung vorhanden: `DevVariants.setDevEnvironment(FabricLoader.isDevelopmentEnvironment())` (SimpleLibFabricClient), aber ohne Getter.
2. Notenblatt (`SheetMusicScreen#init`): bis 7 Knöpfe fest 80 px, bei Platzmangel schmaler → Text abgeschnitten
   (Bild a-rel10 0692: „obehören“, „Importiere“, „hinzufüger“, „Hochlader“).
3. JEI: Plattenpresse steht als Eintrag im gemeinsamen Tab „Special Ways“ (Uses der Presse → 2. Reiter, A sah nur Reiter 1
   „Block Tags“). Entrindungs-Station hat nur eine Info-Seite. Gemeißelte Blöcke: Steinsägen-Rezepte existieren
   (`*_stonecutting.json`, alle 7) und JEI zeigt sie – im A-Bild 0102 ist der 2. Reiter (Steinsäge-Symbol) zu sehen,

4. Landing: `index.html` = `vorschlag-2.html` + Navigation (concepts.py). Die Icon-Galerie „Alle 56 Module“ ist statisch
   (ohne simplelayers, simplechisels, simplebuildingtools). **Zusatzbefund:** seit a-land11 (3d862656b) tragen alle 85 Bilder
   der Basis `data-ico="simplebuilding"` → `fresh_icons` setzt überall das SimpleBuilding-Icon (index.html: 85 Bilder, 1 Bildquelle).
   concepts.py brach zusätzlich mit `AssertionError ['simplelayers']` ab (Kurztext fehlte; gleicher Text wie a-rel10 Fix 3).
5. Probes: `modules/simplebuildingtools/tools/mouse_probe.py`, `modules/simpleinterfaces/tools/keys_probe.py` (xvfb-run, Muster b-small04).

## Umsetzung
1. `DevVariants.devEnvironment()` (Getter); Shops-Knopf nur wenn `devEnvironment()` (Server-Seite bleibt: nur Besitzer, harmlos).
   Entscheidung: nicht `DevVariants.enabled()`, das steht bis zur Veröffentlichung auf an (DEFAULT_ON) – Auftrag sagt „nur Dev-Umgebung“.
2. Knopfleiste: jeder Knopf so breit wie sein Text (+12, min 50; Probehören auch für „Stopp“), so viele wie passen in eine
   zentrierte Zeile, Rest eine Zeile darüber; Code-Bereich/Info-Zeile rücken mit hoch. Vanilla-Knöpfe → Kontrast unverändert.
3. SimpleLib: `RecipeViewer.station(owner, item, entries)` = eigener JEI-Tab je Maschine (Titel + Symbol = Maschine, Maschine ist
   Katalysator). Plattenpresse: 2 Einträge (ohne/mit Farbstoff, WH26-3) im eigenen Tab, Notenblatt-Kopie bleibt in „Special Ways“.
   Entrindungs-Station: ein Eintrag je Block, den eine Axt im Käfig bearbeitet (über `StripWork.step`, also auch Holz anderer Mods,
   Kupfer abschaben/entwachsen), Äxte = alle Items mit Axt-Regeln. `check_jei_coverage.py` kennt `RecipeViewer.station`.
   Tests: `MusicJeiTests` (Station-Tab, Farbstoff-Eintrag), neu `strip_station_has_its_own_viewer_tab`.
4. `vorschlag-2.html`: data-ico je Bild korrigiert (Karten über Namen, Galerie/Icons über alt). `concepts.py`: Icon-Galerie
   „Alle N Module“ wird bei jedem Lauf aus modules.json/modtree erzeugt (Reihenfolge reproduziert den Entwurf exakt), Kurztext
   simplelayers. index/paket/reise/discover neu erzeugt (Alle 59 Module, 60 Mods).
5. Probes im selben sbt-Lauf, nur wenn außer diesem Job kein heavy-Job/Gradle läuft, sonst `PROBES_SKIPPED` → offen.
