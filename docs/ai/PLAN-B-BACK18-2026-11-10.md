## Ist-Stand (b-layers13)
- Eine Dimension `simplelayers:backrooms` (Höhe 64), Generator `BackroomsChunkGenerator` → `BackroomsGrid` (reine Funktion
  aus Seed + Position): Zellen 8×8, Teppich y 1, Räume y 2–6, Decke y 7, Grundgestein y 0 und y 8–63, Türen 66 %,
  Säulenhallen, dunkle Zellen, Büro-/Spinnweben-Zellen. Jigsaw-Sonderräume (Lager/Wasser/dunkel) alle 7 Chunks, Ausgangsraum
  nur alle **40 Chunks** (≈ 640 Blöcke) → der „einfachste Weg“ ist heute nicht schnell.
- Eingang: fehlerhaftes Grundgestein (1/48 Chunks, nur Netherit-Spitzhacke) → Riss → Backrooms; Ausgang: Ausgangstür → Oberwelt
  über dem Eintrittspunkt (Hintertür-Schlüssel: 1500–3000 Blöcke weit).
- Klang: Biom-Schleife `ambient.backrooms.hum` = **Dauerton** + seltenes Klopfen; „Der Lauschende“ (Config, aus).
- Schutz: Effekt `simplelayers:backroom` → `BackroomBlock` nicht abbaubar, Kolben-Mixin; nur Dimension `backrooms`.
- Tests: 22 Modul-Gametests (fabric + standalone); Standalone-Server lädt KEINE Datapack-Dimensionen (Tests prüfen dort nur
  Registry-Einträge, `levelOrRegistryOnly`).

## Entscheidungen (selbst, begründet)
1. **Ebenen = eigene Dimensionen** (gleicher Generator-Typ, Codec-Feld `level`, Standard `lobby` → `backrooms.json` bleibt
   gültig, bestehende Welten behalten Level 0). Neu: `backrooms_warehouse` (Level 1), `backrooms_pipes` (Level 2),
   `backrooms_pools` (Poolrooms), `backrooms_end` (Ausgangs-Ebene). Grund: je Ebene eigener Nebel, eigenes Licht, eigenes Biom
   (Partikel, Klang-Satz) – das trägt die Stimmung; alles in einer 64er-Dimension gestapelt hätte nur eine Nebelfarbe und
   alte Chunks (Grundgestein/Luft über y 8) würden neue Ebenen zerschneiden. Kosten: je Dimension ein ServerLevel, Chunks nur,
   wo Spieler sind. Gefahrenzone „Run“ **nicht gebaut** (optional laut Auftrag; A12: Verfolgung/Schaden = starker Eingriff in eine
   Ebene, die man ohne Vorwarnung betreten kann) → als spätere Option im Plan.
2. **Generatoren rein und MC-frei** (`world/gen/*`, liefern Block-Codes statt BlockStates; Zuordnung Code → BlockState an einer
   Stelle `BackroomsBlocks`). Grund: dieselbe Quelle erzeugt die Runden-Bilder (lokal mit javac/java ausführbar, ohne Gradle) und
   die Pfad-Prüfungen der Gametests; keine Python-Nachbildung, die abweichen kann.
3. **Einfachster Ausgang (Level 0):** Regionen 12×12 Zellen, je Region eine Ausgangszelle (freistehende Wand mit Ausgangstür +
   EXIT-Schild, wie der Jigsaw-Ausgangsraum). Jede Zelle erzwingt eine Tür Richtung Ausgang (erst x, dann z) → Baum, von jeder
   Zelle führt ein Weg mit ≤ 18 Zellen (≈ 150 Blöcke) zum Ausgang. In Zeile und Spalte der Ausgangszelle hängt ein EXIT-Schild
   unter der Decke auf der Seite der Weiter-Tür (Richtung lesbar). Ankunft nie in einer Ausgangszelle (Ankunft dort +2 z).
   Gametest: Breitensuche über die echten Kanten, Obergrenze 18 Zellen.
4. **Verschachtelung:** Level 0 bekommt ein **Obergeschoss** (Teppich y 9, Decke y 15, dunkler, mehr Sackgassen, Türen 58 %),
   verbunden über **Treppenhaus-Zellen** (L-Treppe, Geländer). Level 2 hat zwei Rohr-Etagen, verbunden über **Leiter-Schächte**.
   Level 1 = hohe Halle (8 Blöcke) mit Säulen, Regalgassen, Trennwänden mit Durchgängen und massiven Sackgassen-Wänden.
5. **Übergänge** (Ziel = gleiche x/z, sichere Ankunft je Ebene `arrival`):
   - Noclip-Stellen: ein Riss (vorhandener `rift`-Block, ohne Kollision) in einer Wand → nächste Ebene (L0→L1, L1→L2).
   - Löcher: Riss im Boden (L1/L2 → Poolrooms).
   - Besondere Türen: neuer Block `level_door` (Wartungstür, 2 hoch, ohne Item) → nächste Ebene; in Level 2 **versiegelt**
     (Rätsel, siehe 7) → Ausgangs-Ebene.
   - Ausgangstür (vorhanden) → Oberwelt: Level 0 (einfach), Poolrooms, Ausgangs-Ebene.
6. **Belohnung für schwere Wege:** Truhen per Feature (wie Himmelstruhe) mit eigener Beute je Ebene: Lager (Holz/Faden/Mandelwasser),
   Poolrooms (Mandelwasser, Prismarin, Schwamm, Schlüssel selten), Ausgangs-Ebene (Hintertür-Schlüssel sicher, Diamanten,
   Smaragde, Enderperlen, Goldapfel, Schallplatte).
7. **Rätsel (Nachtrag, optional):** Versiegelte Wartungsluke in Level 2: drei Ventilhebel daneben; die Luke öffnet nur bei der
   richtigen Stellung (aus Seed + Position, nie „alle aus“); jeder Versuch meldet in der Aktionsleiste „x von 3 Ventilen
   stimmen“ (A14) → lösbar durch Nachdenken in ≤ 8 Versuchen. Liminal-Stimmung bleibt (kein Text an Wänden, nur Klicks/Zischen).
8. **Eingang: neue Oberwelt-Struktur „Wartungsschacht“** (Feature, selten, Config `backrooms.bunkerRarity`, 0 = aus):
   Betonplatte, 3×3-Schacht mit Leiter und gelb-schwarzem Kragen, Riss-Boden unten (= Portal), Absperrung aus Pfosten +
   neuem Block `caution_tape` (gelb-schwarzes Band), neue `caution_sign` (Warnschild) an den Pfosten, rote Warnleuchten
   (Redstone-Lampe auf Redstone-Block) an den Ecken. Nur auf flachem, trockenem Boden. **Fehlerhaftes Grundgestein bleibt**
   (ergänzt, ersetzt nicht): sichtbarer, beabsichtigter Weg (Bunker, A14: Gefahr klar erkennbar) + versteckter Zweitweg für
   Bergleute; beide führen nach Level 0. Werte unverändert → keine Config-Brüche.
9. **Klang:** Biom-Dauerton entfällt in allen Ebenen. Neuer Planer `BackroomsAmbience` (Server, nur für den Spieler hörbar,
   Quelle AMBIENT → Vanilla-Regler wirkt zusätzlich): alle 20–60 s ein leiser Einzelklang aus dem Satz der Ebene (Vanilla bevorzugt:
   Tropfen, Lüftung, Klicken, Wasser; eigenes Neon-Brummen/Klopfen), zufällig im Raum versetzt, Config
   `backrooms.ambientVolume` 0–100 (Standard 50, 0 = aus). ElevenLabs **nicht** genutzt (Vanilla reicht, sparsam = null).
10. **Schutz in allen Ebenen:** Effekt in jeder Backrooms-Dimension; geschützt sind `BackroomBlock` + Block-Tag
    `simplelayers:backrooms_structure` (Vanilla-Bauteile der Ebenen), nur innerhalb der Backrooms (Mixin auf
    `BlockStateBase.getDestroyProgress`); Kolben-Regel ebenso. Vorräte (Holz, Spinnweben, Truhen) bleiben abbaubar.
11. Config neu: `backrooms.bunkerRarity`, `backrooms.ambientVolume`, `backrooms.levels` (Übergänge in tiefere Ebenen an/aus).
    Lang EN/DE inkl. Ebenennamen (Aktionsleiste bei Ankunft, A14), Wiki `manual.json`, Guide (generiert), INVENTAR-Eintrag.

Reise-Abkürzung), neue Deko-Blöcke (Warnschild, Absperrband). (2) Änderung: seltene neue Oberwelt-Struktur (klein, abschaltbar)
