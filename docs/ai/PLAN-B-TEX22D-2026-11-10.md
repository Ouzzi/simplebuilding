- Verwechslungen ALT: Kreide = diagonaler Stab wie `stick` (13 px lang, 2 px dick), Mandelwasser = Vanilla-Trankflasche umgefärbt,
  Glitch-Grundgestein ≈ `bedrock` (Abstand 12,3), Tapeten ≈ Sandstein/Birke, Türen ≈ Bruchstein-Grau, Warnschild-Rand lag außerhalb der Modell-UV (1–14).

## 2. Plan
1. Neuer Generator `tools/textures/layers22d_2026_11_10.py` (eigene Pixel, Schritte → `.layers.json`); `layers10.build()` übernimmt dessen
   Texturen (`TEX22D = True`), damit `python3 tools/textures/layers10_2026_11_08.py` die neuen Pixel schreibt; `--check` vergleicht Repo-PNGs mit Neulauf.
2. Neu-Items in `tools/textures/layers22d_new_2026_11_10.py`, Ausgabe außerhalb des Repos: `layers22d_2026_11_10.py --new /root/sb-tools-b/back22/tex22d`
   → `<ebene>/<name>.png` + `.layers.json` (Namen = Konzept-Namen in ASCII-Kleinschreibung wie in der BACK22c-Skizze).
3. Runden ≥ 3 je Textur: erstellen → Verwechslungs-Check (automatisch + Blick per Read auf 5×/10×-Bögen und 3×3-Kacheln) → verbessern.
   Check (`/root/sb-tools-b/back22/tex22d/scr/conf.py`, Vanilla-Pixel nur im Speicher):
   Items = Silhouetten-Überdeckung (IoU, auch gespiegelt) gegen jedes Vanilla-Item, gewichtet mit Farbnähe → „Verwechslung“ = IoU × (1 − ΔFarbe/150);
   dazu IoU/ΔFarbe/Größe gegen das naheliegende Vorbild (Kreide↔`stick`, Mandelwasser↔`potion`, Schlüssel↔`trial_key` …).
   Blöcke = mittlerer Farbabstand auf 4×4-Raster (4 Drehungen) + Helligkeits-Streuung → nächstes Vanilla + Abstand zum Vorbild. Dazu texrate (A8d) und hart (A8b).
4. texrate-Ziellisten: Simple-Layers-Einträge aus `texrate16_targets.json` → `excluded`; `texrate17` bekommt die Ausschluss-Gruppe „Backrooms BACK22d“.
5. Checks: `layers.py check`, `texrate.py --selftest`, `check_missing_textures.py`, `layers10 --check`, `modules/simplelayers/tools/check_data.py`.
   Kein sbt (keine Namens-/Java-Änderung). Wiki-Kopien (`wiki/assets/textures/simplelayers`) erneuert das Bündel-Gen (A).

**Entscheidungen (selbst getroffen):** Kreide = kurzer dicker Stummel (5 px breit, ~8 px lang) mit abgeriebener Spitze und Papierhülse unten
(weiße Kreide blaue Hülse, farbige cremefarbene Hülse mit Aufdruck in der Kreidefarbe) – Auftrag-Beispiel. Kreidebox = grüner Schulkarton statt Holzkiste.
Mandelwasser = Plastikflasche (Name „Stilles Wasser“ bleibt Sache von fl1). Hintertür-Schlüssel: Reide als Tür (vier Schlüssel der Ebenen
sind untereinander verschieden: Tür-Reide / Rautenanhänger / liegender Zylinderschlüssel / Vorhängeschloss). Dampfrohr in 4 Kupferstufen + Rohrende.
Briefkasten mit Front/Seite/Deckel. Poolfliese Mosaik zusätzlich (Konzept „weiß/blau/Mosaik“).
