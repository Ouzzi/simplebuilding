# Plan B-BOAT02: Ofen-Boot einbauen (BOAT40), 02.11.2026

Besitzer: "bitte wie das chest boat nur halt mit ofen". Konzept: docs/ai/PLAN-B-BOAT40-2026-11-01.md (Empfehlungen angenommen).
Branch b-boat02, Basis b-bundle91. Mod: Simple Ovens (standalone), nur 26.3 Fabric getestet.

## Ist-Stand
Nichts vorhanden. Vorbilder: Vanilla `AbstractChestBoat`/`ChestBoat`/`ChestRaft` (26.3), `EndBoatRenderer` (Simple End),
`TieredFurnaceMinecart` (Brennstoff, Rauch). 26.3: Brenndauer ist ein Loot-Kontext-Wert (CookingFuel), daher nehmen wir wie
die Ofenlore das Tag `furnace_minecart_fuel` (Kohle/Holzkohle).

## Umsetzung
- `OvenBoat extends AbstractBoat` (1 Sitz, eine Klasse fuer Boot und Floss), je Holzart ein EntityType
  `simpleovens:<holz>_furnace_boat` bzw. `bamboo_furnace_raft` (10 Stueck, Vanilla-Holzarten).
- Schub wie Ofenlore: Brennstoff 3600 Ticks je Kohle/Holzkohle, max 32000 (Rechtsklick; ist es voll oder nichts in der
  Hand: normal einsteigen). Schub nur bei Brennstoff + Spieler am Steuer + im Wasser, 0.02 Bloecke/Tick^2, Obergrenze
  0.3 Bloecke/Tick (Eisboot ~0.7); Spieler lenkt wie im Boot. Brennstoff brennt nur mit Passagier.
  Abweichung vom Konzept: Obergrenze fest im Code, keine Config-Option (keine Doku-/Wiki-Config-Kette noetig).
- Zerstoeren: droppt das Ofen-Boot-Item (wie Truhenboot-Item); Brennstoff geht verloren.
- Item: `BoatItem` je Holzart, Rezept formlos Vanilla-Boot + Ofen (10 Rezepte, Gruppe furnace_boat), Kreativ-Tab Simple Ovens +
  Vanillas Werkzeug-Tab hinter dem Truhenboot-Bereich (wie die Lore).
- Renderer: `BoatRenderer`-Unterklasse, Vanilla-Boot-Modell/-Textur (nichts kopiert), Ofen (Vanilla-Block, lit bei Brennstoff)
  an der Truhenposition; Rauch bei Brennstoff.
- Item-Icon: Vanilla-Boot-Sprite (layer0) + abgeleitetes Overlay (`item/furnace_boat_overlay`, `furnace_raft_overlay`) wo
  Truhenboot-Sprite vom Boot abweicht, in Ofenfarben; im Build erzeugt (vanilla_derived.py, ovens_boats_2026_11_02.py).
- Lang EN/DE, Wiki-Manual (Feature + je Item), Money: excluded (Boot + Ofen tragen den Preis), Gametests.
- Neo/Forge: Renderer-Registrierung gespiegelt, nicht kompiliert (Vorgabe: nur 26.3 Fabric).
