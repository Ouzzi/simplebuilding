  `UiBoxes/UiMotifs/UiSymbols`, gleiche Maße/Farbe 0xFF4F5560, Stil aus = alte PNG `textures/gui/container/auto_smither.png`).

  `simplebuilding.json` `server.machines.autoSmitherDelayTicks` übernommen; SB blendet die Option auf 26.3 aus
  (`ConfigOptions.MOVED_TO_MACHINES_SMITHER`).
- **IdMoves:** ITEM+BLOCK `auto_smither`, BLOCK_ENTITY_TYPE `simplebuilding:auto_smither` → `simplemachines:auto_smither`
  (NBT gleich: Items, crafting_ticks_remaining), RECIPE `auto_smither`, ADVANCEMENT `recipes/redstone/auto_smither`.
- **Daten:** Blockstates/Modelle/Items/Texturen per git mv aus `mc26_3/overlay` ins Modul (Namespace in JSON umgestellt),
  Rezept/Loot/Rezept-Fortschritt aus `mc26_3/generated` ins Modul, Tags (pickaxe ins Modul, sulfur_cube high_resistance → neue Id),
  Lang EN/DE ins Modul (Block/Item/Container, Tooltip ≤48), SB-26.3-Overlay-Lang ohne die drei Schlüssel.

  `jei_mod_plugin`, suggests jei). **Jade:** kein Muster für den Schmied (SB hatte keins) → nichts.
- **Wiki/Guide/Discover/Testzentrale:** Wiki-Eintrag ins Modul-Manual, Discover-Zeile, Testzentrale-Station um `auto_smither` ergänzt.
- **Tests (Modul `AutoSmitherTests`, Adapter `ModuleGameTest`):** Diamant→Netherit automatisch per Puls, Rüstungsbesatz (smithing_trim),
  Redstone aus/Dauersignal = kein weiterer Vorgang, Trichter sortiert in Slots, Ausgabe nimmt nichts an, Auswurf ohne Container,
