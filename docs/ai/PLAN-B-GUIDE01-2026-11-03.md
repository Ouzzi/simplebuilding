# Plan b-guide01: Mega-Guide „Simple Modpack“ in SimpleLib (03.11.)

Besitzer 03.11. (Punkt 6, /root/b-antworten-20261103b.md): Mega-Guide = Simple Modpack, je Super-Mod ein Buch;
oben Lesezeichen je Super-Mod, links/rechts Kapitel-Lesezeichen je Super-Mod; Freischaltung wie bisher über
Advancements; Tooltip nur „Your first steps into SimpleMods“; existiert mit jeder Simple-Mod (auch nur Simple Fun).
Nur 26.3 Fabric. Basis 9f69c3ce1 (Production).

## Ist-Stand
- SimpleBuilding 26.3: ein Item `simplebuilding:guide_book` (`GuideBookItem`, `GuideBookScreen`, 1067 Zeilen) mit
  11 Lesezeichen (Book-Enum), Kapitel-Freischaltung über Gate-Rezepte + Tab-Advancement `simplebuilding:guides/*`
  (`GuideTabs`/`GuideUnlocks`, Entity-Tag + `GuideStatePayload`), Tooltip listet freigeschaltete Kapitel.
  Rezept Buch + Werkbank; FTB `stage_1` (26.3-Overlay) schenkt/verlangt `simplebuilding:guide_book`.
- 34 Module: `tools/guides/module_guides.py` erzeugt je Modul ein Vanilla-`WrittenBookItem` `<ns>:guide_book`
  (Item-Module, Rezept Buch + Vanilla-Item, FTB-Startkapitel) bzw. `/<ns> guide` (4 Client-Module). Seiten =
  Sprachschlüssel `<ns>.guide.page.<n>(.title)`.
- Fabric: alle Item-Module bündeln SimpleLib schon (`include project(':modules:simplelib:fabric')`, CMD24/UI-Bausteine).
  Simple Fun allein lädt also SimpleLib mit. NeoForge/Forge bündeln es nur teilweise (nicht Teil dieses Punkts).
- SimpleLib: `CreativeTabPolicy` (zentraler Tab-Filter), `IdMoves`, Payload-Muster (FreeLookRules), Framework gebündelt.

## Entscheidungen (selbst getroffen, begründet)
1. **Item `simplelib:modpack_guide`** „Simple Modpack“ (DE gleich), stapelt 1, Tooltip eine Zeile
   „Your first steps into SimpleMods“ / „Deine ersten Schritte in die SimpleMods“ (keine Kapitelliste).
   Textur = die bestehende 26.3-Handbuch-Textur des Besitzers (Kopie + Ebenen-JSON), keine neue Pixelkunst.
   Rezept formlos Buch + Werkbank (wie bisher das SB-Handbuch); Tab: Vanilla „Werkzeuge“ (SimpleLib hat keinen Tab).
2. **Datenvertrag** (keine Klassenkopplung): jede Mod legt `assets/<ns>/simplelib/modpack_guide.json` ab
   (`section` = Super-Mod-ID, `section_name`/`section_icon`, `order`, optional `screen`, `chapters[]` mit `id`,
   `title`, `icon`, `pages`, `page_key`, optional `advancement`, `hint`). SimpleLib liest alle Dateien clientseitig
   (ResourceManager) – auch Client-Mods ohne SimpleLib-Abhängigkeit können so beitragen.
3. **Abschnitte (obere Lesezeichen):** gruppiert nach `section`, wenn die Super-Mod selbst einen Beitrag hat
   (also installiert ist); sonst bekommt der Beitrag ein eigenes oberes Lesezeichen (nur Simple Fun → „Simple Fun“).
   Reihenfolge `order`, dann Name.
4. **Kapitel (seitliche Lesezeichen):** je Modul ein Kapitel (seine bisherigen Buchseiten); rechts 8, links unter
   „Inhalt“ 6, der Rest über die Inhaltsseite (Liste aller Kapitel mit Schloss). Seiten wie bisher ≤ 13/14 Zeilen.
5. **Freischaltung:** Kapitel mit `advancement` öffnen, sobald der Spieler es hat. Der Client fragt beim Öffnen
   (`ModpackGuideQueryPayload`, max. 256 IDs) und bekommt die erledigten zurück (`ModpackGuideStatePayload`).
   Modul-Kapitel: neues unsichtbares Advancement `<ns>:guide/chapter` (Kriterium: das typische Vanilla-Item des
   bisherigen Buchrezepts im Inventar). Kreativ: alles offen. SB-Kapitel unverändert (Gate-Rezepte → `guides/*`).
6. **SimpleBuilding = eigener Bildschirm:** SB meldet über `com.simplelib.api.client.ModpackGuideScreens` (26.3-Overlay
   `LibClientServices`) seinen `GuideBookScreen` für Abschnitt `simplebuilding`; der zeichnet die oberen Lesezeichen
   (`ModpackGuideBar`) und ein zusätzliches Lesezeichen „Weitere Simple Mods“ → SimpleLib-Bildschirm mit den
   Sub-Mod-Kapiteln dieses Abschnitts. 26.2-Zwilling: No-op.
7. **Migration (Umwandlung statt IdMoves):** alte Bücher bleiben registriert (Welten, Preise, Discover, Tests
   unverändert), verlassen aber jeden Kreativ-Tab (`CreativeTabPolicy`), Rezepte/FTB-Kapitel der Modul-Bücher
   entfallen. Ein altes Modul-Buch wird beim Benutzen zum Mega-Guide, das SB-Handbuch beim Einloggen
   (`GuideUnlocks.onJoin`). SB-Rezept `guide_book` auf 26.3 per Overlay abgeschaltet (Bedingung false), IdMoves
   Rezept/Advancement → `simplelib:modpack_guide`. Begründung: IdMoves hätte ~195 Dateien in 30 Modulen berührt.
8. **FTB:** SB-`stage_1` (26.3) gibt/verlangt den Mega-Guide; SimpleLib bringt ein eigenes Startkapitel, das nur
   ohne SimpleBuilding installiert wird; Modul-Startkapitel entfallen (`installQuests` bleibt, findet nichts).
9. NeoForge/Forge: keine Änderung (nur 26.3 Fabric); Mega-Guide-Netzwerk nur Fabric → Port-Run-TODO.
