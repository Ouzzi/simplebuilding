# Contributing to Simple Mods

Thank you for your interest. The Simple Mods are **source-available, all rights reserved** (see `LICENSE`,
SPDX `LicenseRef-SimpleMods-ARR`). Pull requests are welcome under the following rules.

## Contributor License Agreement (required)

Every contributor must agree to the [Contributor License Agreement](CLA.md) before a pull request can be merged.
You keep your copyright; you grant the Author the rights listed in the CLA, including the right to relicense.

How to sign: open your pull request, then post this comment once:

    I have read the CLA Document and I hereby sign the CLA

The `CLA` check (`.github/workflows/cla.yml`) records the signature and turns green. One signature covers all your
future pull requests to this repository. Pull requests without a signature are not merged.

## What to contribute

- Bug fixes, translations, tests, documentation; for larger features open an issue first.
- No Minecraft/Mojang assets and no third-party code or art whose license does not allow it. Flag any third-party
  material in the pull request.
- Follow `AGENTS.md` (project rules) and keep every module playable on its own
  (`docs/ai/PRINZIPIEN-MODUL-UNABHAENGIGKEIT.md`).

## Kurz auf Deutsch

Beiträge sind willkommen, aber nur mit unterschriebener [CLA](CLA.md): im Pull Request einmal den Satz oben als
Kommentar posten. Keine Mojang-Assets, keine fremden Inhalte ohne passende Lizenz.
