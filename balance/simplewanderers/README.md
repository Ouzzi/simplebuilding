# Simple Wanderers producer data

Balancing-Zentrale store of Simple Wanderers (`modules.json` `paths.balanceDir`; versions and applied logs
land here). The tunable numbers are read from the sources, nothing is duplicated:

- Server config `config/simplewanderers-server.json`: `WandererConfig.java` (named defaults and hard bounds:
  `respawnDays` 7 (0-60), `rerollDays` 3 (1-14), `restockDays` 1.5 (0.5-reroll), `villageRadius` 48 (16-64),
  `homeRadius` 24 (8-48), switches `enabled`, `horse`, `raidBlocksSpawn`, `biomeAssortment`).
- Offers: ordinary 26.3 data under `modules/simplewanderers/shared/resources/data/simplewanderers/`
  (`trade_set/wanderer/*`, `tags/villager_trade/wanderer/*`); the split of the Vanilla `common` group with the
  wandering trader lives in `data/minecraft/trade_set/wandering_trader/`.
- Price-list heads (Simple Money): the 14 heads of the 0.1 group are rows with `merchant: village_wanderer` in
  `modules/simplemoney/shared/resources/data/simplemoney/money/simplemobheads/prices.json` (generated by
  `modules/simplemobheads/tools/generate_heads.py`), switched by Simple Money's `trades.enableWandererTrades`.
